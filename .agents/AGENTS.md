# Project-Specific Rules

## Resume and Portfolio Synchronization
- **Rule**: Whenever the user asks to update their resume, or if you modify/detect changes to the resume files (`public/samuvel-johnson.pdf` or `src/constants/resumeData.json`), you **MUST** remind the user to keep both the PDF resume (`public/samuvel-johnson.pdf`) and the portfolio JSON data (`src/constants/resumeData.json`) synchronized.
- **Action**: Offer to help update the JSON structure (`src/constants/resumeData.json`) if they provide the updated details for their PDF resume, or vice versa, to ensure the website is always up to date.
